# EatMate 🥗

**Dein einfaches Ernährungstagebuch — ganz ohne Kalorienzählen.**

🌍 [Português](README.md) · [English](README.en.md) · [Español](README.es.md) · **Deutsch** · [Français](README.fr.md) · [Italiano](README.it.md)

Schreib auf, was du gegessen hast, so wie du es sagen würdest — _„eine Tasse Kaffee und zwei Scheiben Vollkornbrot“_ — und EatMate erkennt die Lebensmittel von selbst. Nach 7 Tagen zeigt ein **Thermometer** die Qualität deiner Ernährung als Note von **A bis E** (im Stil des Nutri-Score), dazu einen **ausführlichen Bericht** für deine Ernährungsberatung oder zum Einfügen in eine KI (ChatGPT, Gemini, Claude…).

## 👉 EatMate öffnen

### **[malonefreak.github.io/EatMate](https://malonefreak.github.io/EatMate/)**

Einfach den Link auf dem Handy oder Computer öffnen. **Kein App-Store, kein Konto, keine Kosten.** Nach dem ersten Besuch funktioniert es sogar offline.

## 📱 Auf den Startbildschirm legen (optional)

- **Android (Chrome):** Link öffnen, auf das Menü **⋮** tippen und **App installieren** (oder **Zum Startbildschirm hinzufügen**) wählen.
- **iPhone (Safari):** Link öffnen, auf **Teilen** (das Quadrat mit dem Pfeil) und dann auf **Zum Home-Bildschirm** tippen.
- **Computer (Chrome oder Edge):** auf das Installations-Symbol in der Adressleiste klicken.

## ✍️ So funktioniert’s

1. **Sag uns deinen Namen.** Das war’s — keine E-Mail, kein Passwort.
2. **Tippe auf „Mahlzeit eintragen“** und schreib in deinen Worten, was du gegessen hast. EatMate trennt die Lebensmittel, macht Vorschläge beim Tippen und zeigt die Note jedes Lebensmittels. Eintragen geht sofort oder später, auch für vergangene Tage.
3. **Vertippt?** Im **Verlauf** kannst du jede Mahlzeit bearbeiten oder löschen.
4. **Nach 7 Tagen** erscheint das **Thermometer** auf dem Startbildschirm mit deiner Punktzahl (0–100 und A–E).
5. **Tippe auf das Thermometer** für den ganzen Bericht — zum **Kopieren für eine KI**, **als PDF speichern** oder **teilen**.
6. **Jede Woche** wird ein Bericht unter **Berichte** gespeichert. Später etwas korrigiert? Den Bericht mit einem Tipp neu erstellen.

## 🌍 Sprachen

EatMate spricht **Portugiesisch, Englisch, Spanisch, Deutsch, Französisch und Italienisch**. Es öffnet sich in der Sprache deines Handys; unter **Profil → Sprache** kannst du jederzeit wechseln — auch die Lebensmittelnamen, die es versteht.

## 🔒 Deine Daten gehören dir

Keine Anmeldung, kein Server, keine Werbung, keine Tracker. Alles bleibt **nur auf deinem Gerät**. Neues Handy? **Profil → Backup exportieren** und auf dem neuen Handy **Backup wiederherstellen**.

> ⚠️ Die Noten sind Schätzungen, die dir helfen, Muster zu erkennen. EatMate ersetzt keine Ernährungsberatung.

Neue Versionen findest du unter [Releases](https://github.com/MaloneFreak/EatMate/releases); die App meldet sich, wenn ein Update bereitsteht. Ein Problem gefunden? [Issue eröffnen](https://github.com/MaloneFreak/EatMate/issues).
